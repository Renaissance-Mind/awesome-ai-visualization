# Chinese and English versions

The website provides Chinese at `?lang=zh` and English at `?lang=en`.
Chinese is the default for URLs without a language. The header language links
preserve the current query, topic, filters, revealed batches and tool detail.
Navigation and refresh retain the language in the URL.

## Copy sources

- `src/lib/i18n.ts`: interface messages, formatting and language-aware links.
- `src/LocaleContext.tsx`: the current language for components.
- `data/catalog.yml`: canonical English tool descriptions and facts.
- `data/catalog.zh-CN.json`: Chinese descriptions with the corresponding
  English source text, so changes to the source can be detected.
- `src/data/editorial.ts`: paired concise introductions for selected tools.
- `src/lib/labels.ts`: translated taxonomy labels; filter values stay canonical.

The generated catalog contains both `note` and `noteZh`. Search indexes both
languages. Resource names and official screenshot contents retain their source
identity. The document language, title, description, accessible control labels
and README destination follow the selected language.

## Updating descriptions

1. Edit the canonical catalog.
2. Run `npm run translate:catalog` for a first translation of new or changed
   descriptions. The optional helper sends public catalog text to Google
   Translate, preserves technical names, checks entry boundaries and saves
   completed batches. It can resume from the saved file after a service error.
3. Review the Chinese wording, especially technical terms and capability claims,
   and edit `data/catalog.zh-CN.json` as needed.
4. Run `npm run check:frontend` and `npm run build`.

Translations are committed as local data. Frontend builds read these files
without calling a translation service. Generation fails if a Chinese description
is missing or its stored source no longer matches the canonical English note.

Frontend checks cover all descriptions, English taxonomy and interface-message
coverage, interpolation parameters, language-aware URLs and bilingual search.
